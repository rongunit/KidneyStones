## To install the Docker container and run the server:

Download and run the container using the following console commands:

```bash
docker pull author/ksd:0.2
```
```bash
docker run -d -p 8000:80
```

Open `localhost:8000/` in your browser.




## Brief description of file functionality

**server.py** – The API server and all its functionality, including the following endpoints:

  - `'/'` – **GET**, returns the home page  
  - `'/uploadfiles'` – **GET**, returns the file upload page (using JinjaTemplate)  
  - `'/uploadpatient'` – **POST**, reads, saves (in the `/uploads` folder), and returns `model.prediction` for the uploaded file (supports multiple file uploads, but only returns the result of the last one)  
  - `'/graph'` – **GET**, returns a page with a graph pre-generated by the model (JinjaTemplate)  
  - `'/files'` – **GET**, returns a list of all files uploaded to the server  
  - `'/deletefiles'` – **GET**, deletes all uploaded files  
  - **[not used yet]** `'/files/{file_name}'` – **GET**, returns a sample of data from the uploaded file `{file_name}` (supports `.txt`, `.xlsx` formats)  
  - **[deprecated]** `'/upload'` – **POST**, uploads files to the server and saves them in the `uploads` folder  

---

**Dockerfile**, `docker-compose.yaml`, `.dockerignore` – Docker-related files used to build an image and successfully run the server.

**base.html** – Base webpage with navigation, inherited by other pages.

**index.html** – Home page.

**upload/index.html** – Page for uploading patient files to the server.

**graph/index.html** – Displays a graph generated by the ML model.

**files/index.html** – Lists uploaded files with an option to clear the folder.
